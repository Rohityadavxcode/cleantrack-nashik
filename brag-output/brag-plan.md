# Brag Plan: CleanTrack Nashik

## What is this app?
CleanTrack Nashik is a single unified civic problem reporting portal for Nashik that empowers citizens to report civic issues (garbage accumulation, potholes, open drainage, broken streetlights) on the spot with real-time camera capture, high-precision GPS geo-tagging, automated administrative ward routing, and public complaint tracking.

## The angle
No more running between 5 municipal offices or navigating confusing bureaucratic departments. Stand at the issue location, open CleanTrack Nashik, snap a live photo, auto-detect GPS within ±8.5m, and get an instant tracking ID (`CTN-2026-XXXXXX`) with end-to-end resolution visibility.

## Hook (first 2-3 seconds)
Big bold civic pain statement: "STILL VISITING 5 DIFFERENT OFFICES FOR NASHIK CIVIC PROBLEMS?" accompanied by pulsing civic alert tags (Garbage, Potholes, Open Drainage, Broken Lights) snapping onto the screen with Marathi bilingual sub-captions.

## Key moments (the middle)
- **On-the-spot Camera Viewfinder:** Live mobile camera HUD with reticle, "Capture Photo" trigger, and instant image compression with timestamping.
- **Precision GPS & Ward Geofencing:** Auto-detected coordinates (`20.0053° N, 73.7898° E`), accuracy radius (±8.5m), and automatic routing to Nashik Municipal Corporation administrative zones (Panchavati, Nashik West, CIDCO).
- **Instant Complaint ID & Status Timeline:** Unique reference number `CTN-2026-894215` with a real-time status tracker (Submitted → Under Review → Assigned → Resolved).

## Outro / punchline
"Report. Track. Improve Nashik. One unified platform for 1.5 million citizens." URL callout: `cleantrack-nashik.vercel.app`.

## User flow worth showing
1. **Entry:** Tap "Report a Problem" on CleanTrack Nashik.
2. **Key Action:** Real-time Camera capture + instant GPS detection on Nashik map.
3. **Result:** Instant Complaint Reference ID `CTN-2026-894215` and transparent status timeline.
